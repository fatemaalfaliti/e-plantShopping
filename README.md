# Paradise Nursery - e-plantShopping

Paradise Nursery is an online plant shop built with React and Redux Toolkit.
The application allows users to browse a variety of houseplants, add them to a shopping cart,
adjust quantities, and view the total cost before checkout.

## Features

- **Landing Page:** Company name, background image, a paragraph about the company, and a "Get Started" button.
- **Product Listing Page:** Houseplants grouped into categories, each with a thumbnail, name, description, price, and an "Add to Cart" button.
- **Shopping Cart Page:** Shows each plant in the cart with its thumbnail, name, unit price, quantity controls, subtotal, and a delete button.
- **Navigation Bar:** Links to Home, Plants, and Cart, with a cart icon showing the total number of items.
- **State Management:** Cart state is managed with Redux Toolkit (CartSlice).

## Technologies Used

- React
- Redux Toolkit
- Vite
- CSS
